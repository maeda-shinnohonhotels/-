# 人事評価デスク

ホテル向けの人事評価ツールです。評価の進捗と集計の管理、評価コメントのAI下書き、評価の偏りのチェックを1つの画面で行います。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | ブラウザでそのまま開ける版。入力内容は保存されません（見本データでの動作確認用）。 |
| `artifact/hyoka-desk.html` | claude.ai のアーティファクトとして公開している版の元ファイル。データの保存、AI下書き、CSV保存はこちらで動きます。 |

公開中のツール: https://claude.ai/artifact/4WdSuAjM1a5U54H9L1yjLV

## 主な機能

- 進捗・集計：未着手 → 自己評価済 → 一次評価済 → 二次評価済 → 面談済 の管理と、部署別の平均点・ランク分布
- 評価者：現場責任者・執行役・取締役から選択。一覧はタブで絞り込み
- 評価入力：評価項目ごとの5段階評価、事実メモ、AIによる所見・面談ポイント・次期目標の下書き
- 評価項目の設定：Excelから「項目名・説明・ウェイト」を貼り付けて変更
- マネーフォワード クラウド給与との連携：従業員一覧CSVの取り込み（従業員番号で突き合わせ）と、評価結果のCSV書き出し
- 運用チェック：甘め・辛め・中心化の傾向、評価の遅れ、ランク分布と目安の比較

## データの扱い

評価データはこのリポジトリには含まれません。claude.ai 上のアーティファクトの保存領域に保存されます。
